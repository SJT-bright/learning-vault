# 学习资产库 Learning Vault

学习资产库是一款在 macOS 本机运行的 Electron 桌面应用，用来把零散的学习资料收进一个可搜索、可复习、可继续使用的资料库。默认使用本地规则归类；AI 分类与摘要需要用户自行配置兼容接口。

## 主要功能

- **快速收录**：通过屏幕边缘悬浮入口、快捷键或拖拽，收录链接、文档、图片、视频索引、聊天记录与随手笔记。
- **整理与查找**：本地自动归类，支持自定义分类关键词、全文搜索、标签和筛选；文档可提取正文与图片。
- **从资料到行动**：从聊天消息提取结论、待办、方法和点子，保留来源跳转；记录实际使用、改进版本和点子进展。
- **复习与复盘**：闪卡式间隔复习、每日与每周复盘，帮助回看积累并跟踪成果。
- **图片收藏夹**：收集图片、分类并记录提示词，支持从资料库入口打开。
- **本地数据管理**：资料默认保存在本机，支持 JSON 备份与恢复；可选 AI 接口由用户自行配置。

## 运行

需要 macOS、Node.js 和 npm。

```bash
npm ci
npm start
```

运行 `npm run selfcheck` 可检查主要数据与规则逻辑。`npm run app` 会生成指向当前源码目录的 macOS 启动器。应用数据默认位于 `~/Library/Application Support/学习资产库/`，不包含在本仓库中。
